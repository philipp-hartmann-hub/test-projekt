Lastenheft — lesbare Exportversion (ohne Codeblöcke)
====================================================

Dateien:
  LASTENHEFT.html          Hauptdokument (im Browser oder Word öffnen)
  LASTENHEFT-DOKUMENT.md   Bereinigtes Markdown (optional für Pandoc)
  images/                  Diagramme als PNG

In Microsoft Word:
  1. Word → Datei → Öffnen → LASTENHEFT.html wählen
  2. Datei → Speichern unter → Word-Dokument (.docx)

Erneut erzeugen (aus Projektroot):
  node scripts/export-lastenheft-dokument.js
